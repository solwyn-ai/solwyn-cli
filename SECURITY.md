# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it privately by emailing `security@solwyn.ai` with:

- a description of the issue and its impact;
- steps or a minimal example that reproduce it; and
- any suggested mitigation, if known.

Do not include secrets, credentials, prompts, responses, or other sensitive customer data. We will acknowledge the report, investigate it, and coordinate remediation and disclosure with the reporter.
