---
title: Status
---

`solwyn status` combines project budget state with the fixed 24-hour provider
health view. Select a project through `--project`, `SOLWYN_PROJECT_ID`, or the
configured default. Project keys and JWT login both support the base project
reads.

```sh
solwyn --project proj_example status
solwyn --project proj_example status --forecast --failovers
solwyn --json --project proj_example status
```

`--forecast` adds the month-to-date EOM forecast, daily burn rate, 95% confidence
interval, and insufficient-data marker. `--failovers` adds Core's common seven-day
top-50 failover view and prints its unknown-total limit to stderr. Both sections
remain optional in `solwyn.status.v1`.

When the active credential is a JWT, status also reads the account overview and
adds one account savings summary. A null savings result renders as `—`; it is
never converted to zero. Project-key status remains a two-request project read
and does not attempt the JWT-only overview endpoint.
