---
title: Local configuration
---

Inspect and update non-secret local configuration. These commands run offline,
require no credentials and emit plain text, including when global `--json` is
selected. Allowed keys are `api_url`, `credential_store` (`auto`, `keyring` or
`file`; see [login](login.mdx)) and `format`; credentials
belong in the credential store (`solwyn login`) or explicit environment input.

```sh
solwyn config list
solwyn config set format json
solwyn config get api_url
```

Explicit global flags override environment settings, which override configured
defaults. `config set` writes only the key it sets and keeps the keys already
saved; it never writes a default into `config.toml`. Setting
`credential_store` to `auto` removes the key, since `auto` is the default. There is no computer-wide default project: a repo names its project in
`.solwyn.env` (see [init](init.mdx)). A `default_project` left in `config.toml`
by an older CLI is ignored and dropped on the next config write, and
`config set default_project` exits 2 (`Invalid configuration key`).

`config list` shows the effective API URL and where it came from, not only the
saved value: `--api-url`, `SOLWYN_API_URL`, config, or the default
`https://api.solwyn.ai`. `config get api_url` still prints the saved value.

```text
api_url=https://api.staging.example.test (from SOLWYN_API_URL)
```

`solwyn doctor` reports the same thing as its first check (`API URL: <url>
(<source>)`) and, with `--json`, as `api_url` with `url` and `source` (`flag`,
`environment`, `config` or `default`).

Global `--project`, `--api-url` and output flags precede the command.
Use `--json` for the schema named below unless the command emits plain text.

## `solwyn config`

Inspect and update local configuration.

```console
Usage: solwyn config [OPTIONS] COMMAND [ARGS]...
```

```text
Endpoint: local configuration router
Auth: local (none)
Exit codes: 0 success; 2 usage
JSON schema: none (subcommands emit plain text)
```

## `solwyn config get`

Print one configuration value.

```console
Usage: solwyn config get [OPTIONS] KEY
```

| Argument or option | Meaning | Default |
| --- | --- | --- |
| `KEY` | `Configuration key to read. (STRING; required)` | `None` |

```text
Endpoint: local configuration read
Auth: local (none)
Exit codes: 0 success; 2 usage
JSON schema: none (plain text value)
```

## `solwyn config list`

Print every allowlisted value; api_url shows the effective URL and source.

```console
Usage: solwyn config list [OPTIONS]
```

```text
Endpoint: local configuration read
Auth: local (none)
Exit codes: 0 success; 2 usage
JSON schema: none (plain text key/value list)
```

## `solwyn config set`

Validate and persist one configuration value.

```console
Usage: solwyn config set [OPTIONS] KEY VALUE
```

| Argument or option | Meaning | Default |
| --- | --- | --- |
| `KEY` | `Configuration key to update. (STRING; required)` | `None` |
| `VALUE` | `New configuration value. (STRING; required)` | `None` |

```text
Endpoint: local configuration write
Auth: local (none)
Exit codes: 0 success; 2 usage; 3 credential lock (credential_store only)
JSON schema: none (human confirmation on stderr)
```
