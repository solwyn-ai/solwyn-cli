---
title: Project keys
---

Inspect metadata, rotate or revoke keys for the selected project with a Solwyn
login, and hand the stored key to an SDK. Metadata never reveals existing key
material. Rotation's replacement key is shown once; store it securely. Omitted
`--scope` keeps its scope. `--grace-seconds` is 0–604800 seconds; omission uses
Core's default grace period. Zero grace invalidates the old key immediately.
Revoke takes an identifier, never raw key material, and hard-revokes it without
minting a replacement. Rotate and revoke need a browser approval when you use a
Solwyn login (see [approvals](approvals.mdx)).

```sh
solwyn --project proj_example keys show
solwyn --project proj_example keys rotate --grace-seconds 3600 --yes
solwyn --project proj_example keys revoke --key-id key_example --yes
solwyn keys env
```

`keys env` reads the project key stored for this API and prints one line to
stdout, nothing to stderr, so `eval "$(solwyn keys env)"` exports it for the
SDK in the current shell:

```text
export SOLWYN_API_KEY=sk_proj_0123...cdef
```

It exits 3 with `authentication_required` when no key is stored; it never reads
`SOLWYN_API_KEY`. The CLI never writes `.env` or any other file containing the
key. Do not put key material in arguments or repository configuration.

Rotate and revoke display the selected project and effects before interactive
confirmation or `--yes`. Non-TTY invocations without `--yes` exit 2 with
`confirmation_required` before credentials or HTTP. Decline, EOF or Ctrl-C exits
2 with `confirmation_declined` without a mutation. Preview, prompt and echo use
sanitized stderr; stdout retains the existing successful JSON/table schema.

Global `--project`, `--api-url` and output flags precede the command.
Use `--json` for the schema named below unless the command emits plain text.

## `solwyn keys`

Recover from leaked or expired project keys, and hand a key to an SDK.

```console
Usage: solwyn keys [OPTIONS] COMMAND [ARGS]...
```

```text
Endpoint: composite router for project-key subcommands
Auth: login
Exit codes: 0 success; 2 usage
JSON schema: varies by subcommand
Metadata help never reveals existing key material.
```

## `solwyn keys env`

Print an export line for the stored project key.

```console
Usage: solwyn keys env [OPTIONS]
```

```text
Endpoint: local credential store read
Auth: local (stored project key)
Exit codes: 0 success; 2 usage; 3 no stored project key
JSON schema: solwyn.keys-env.v1
Prints one export line to stdout and nothing to stderr, so eval "$(solwyn keys env)" works.
Never writes .env or any other file.
```

## `solwyn keys revoke`

Hard-revoke a project key without minting a replacement.

```console
Usage: solwyn keys revoke [OPTIONS]
```

| Argument or option | Meaning | Default |
| --- | --- | --- |
| `--key-id` | `Identifier of the key to hard-revoke. (STRING; required)` | `None` |
| `--yes` | `Acknowledge the displayed effects without prompting. (BOOL)` | `False` |

```text
Endpoint: DELETE /api/v1/projects/{project}/key/{key_id}
Auth: login
Exit codes: 0 success; 1 generic/API; 2 usage or confirmation; 3 auth; 5 not found; 6 browser approval required, pending, denied or expired
JSON schema: solwyn.keys-revoke.v1 (CLI output after bodyless 204)
Accepts only a key identifier; never pass key material.
Effects are shown before interactive confirmation or --yes; non-TTY requires --yes.
```

## `solwyn keys rotate`

Rotate the active key and reveal its replacement exactly once.

```console
Usage: solwyn keys rotate [OPTIONS]
```

| Argument or option | Meaning | Default |
| --- | --- | --- |
| `--grace-seconds` | `Seconds the old key remains valid (0 through 604800). (INT)` | `None` |
| `--scope` | `Scope for the replacement key; omit to keep the current scope. (Choice(['full', 'read_only']))` | `None` |
| `--yes` | `Acknowledge the displayed effects without prompting. (BOOL)` | `False` |

```text
Endpoint: POST /api/v1/projects/{project}/key/rotate
Auth: login
Exit codes: 0 success; 1 generic/API; 2 usage or confirmation; 3 auth; 5 not found; 6 browser approval required, pending, denied or expired
JSON schema: solwyn.keys-rotate.v1
Effects are shown before interactive confirmation or --yes; non-TTY requires --yes.
The replacement key is shown exactly once; keep it in a secret manager or solwyn login --with-key.
```

## `solwyn keys show`

Show active project-key metadata without revealing key material.

```console
Usage: solwyn keys show [OPTIONS]
```

```text
Endpoint: GET /api/v1/projects/{project}/key
Auth: login
Exit codes: 0 success; 1 generic/API; 2 usage; 3 auth; 5 not found
JSON schema: solwyn.keys-show.v1
Shows metadata only and never reveals existing key material.
```
