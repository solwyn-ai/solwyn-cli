# Preview invitations

```sh
solwyn invite show
```

Tokens come only from a hidden terminal prompt or bounded stdin. There is no token
argument, flag, environment variable or file workflow. Never put a token in shell
history. One final LF/CRLF is accepted; multiple tokens, URLs, whitespace,
controls and inputs above 4096 ASCII URL-safe characters are rejected with a fixed
error. No token or token URL appears in command results.

`invite show` uses an unauthenticated GET without resolving or sending credentials.
Its strict `solwyn.invite.show.v1` result has `account_name`, nullable
`inviter_email`, `role`, and `expires_at`. Invalid, expired, revoked or consumed
invitations return fixed `invitation_gone` guidance (exit 1).

`solwyn invite accept` is retired. It exits 2 with `invite_accept_retired`:
"Accept the invitation from the link in your email, then run solwyn login." The
emailed link handles signup, email verification and joining in the browser.

Invitation preview remains a CLI workflow. MCP has no token-entry or accept tool;
authenticated roster and invitation list reads are available there. See
[team management](team.mdx).
