---
title: Notification channels
---

Channels belong to the account. Reads require a Solwyn login; create/update/test/delete require the owner's
login and a one-time browser approval for each change (see [approvals](approvals.mdx)). Integrations
require Production or above. Supported types are Slack, PagerDuty, Teams,
Discord and Telegram. Secret input comes from stdin or `SOLWYN_CHANNEL_SECRET`,
never secret arguments. `--config-stdin` reads a type-specific JSON object.
List/show responses mask integration secrets.

```sh
solwyn channels list
solwyn channels show CHANNEL_ID
```

Create/update require the type's documented configuration. Slack supports a
webhook or bot token plus destination; PagerDuty uses a routing key;
Teams/Discord use webhooks; Telegram uses bot token plus chat id. Test sends a
real delivery; delete removes the channel and its project notification and
budget-rule routing references throughout the authenticated account. Delete
shows the channel identifier and account scope before interactive confirmation
or `--yes`. Non-TTY without `--yes` exits 2 (`confirmation_required`) before
credentials or HTTP; decline, EOF or Ctrl-C exits 2 (`confirmation_declined`)
without mutation. Effects, prompt and echo use sanitized stderr; stdout keeps
the existing success schema.

```sh
solwyn channels delete CHANNEL_ID --yes
```

Global `--project`, `--api-url` and output flags precede the command.
Use `--json` for the schema named below unless the command emits plain text.

## `solwyn channels`

Manage reusable account notification channels.

```console
Usage: solwyn channels [OPTIONS] COMMAND [ARGS]...
```

```text
Endpoint: composite router for channels subcommands
Auth: varies by subcommand
Exit codes: 0 success; 2 usage
JSON schema: varies by subcommand
```

## `solwyn channels create`

Create an owner-managed channel using stdin or environment credentials.

```console
Usage: solwyn channels create [OPTIONS]
```

| Argument or option | Meaning | Default |
| --- | --- | --- |
| `--type` | ` (Choice(['slack', 'pagerduty', 'teams', 'discord', 'telegram']); required)` | `None` |
| `--name` | ` (STRING; required)` | `None` |
| `--secret-stdin` | ` (BOOL)` | `False` |
| `--config-stdin` | `Read the type-specific config JSON object from stdin, including any optional secrets. (BOOL)` | `False` |
| `--secret-field` | `Secret field name only; defaults to the type's primary secret. (STRING)` | `None` |
| `--channel` | `Slack destination ID for bot-token mode. (STRING)` | `None` |
| `--chat-id` | `Telegram destination ID. (STRING)` | `None` |

```text
Endpoint: POST /api/v1/account/notification-channels
Auth: login; owner for mutations
Exit codes: 0 success; 1 generic/API or delivery failure; 2 usage; 3 auth; 5 not found
JSON schema: solwyn.channels.v1
Secrets only through --secret-stdin, --config-stdin JSON, or SOLWYN_CHANNEL_SECRET; never command arguments.
Slack requires webhook_url or bot_token + channel; PagerDuty routing_key; Teams/Discord webhook_url; Telegram bot_token + chat_id. All types require Production+.
```

## `solwyn channels delete`

Delete a channel and remove its project and rule routing references.

```console
Usage: solwyn channels delete [OPTIONS] CHANNEL_ID
```

| Argument or option | Meaning | Default |
| --- | --- | --- |
| `channel_id` | ` (STRING; required)` | `None` |
| `--yes` | `Acknowledge the displayed effects without prompting. (BOOL)` | `False` |

```text
Endpoint: DELETE /api/v1/account/notification-channels/{channel_id}
Auth: login; owner for mutations
Exit codes: 0 success; 1 generic/API or delivery failure; 2 usage or confirmation; 3 auth; 5 not found
JSON schema: solwyn.channels.delete.v1
Effects are shown before interactive confirmation or --yes; non-TTY requires --yes.
Core removes the channel ID from project notification settings and every budget rule's channel_ids.
```

## `solwyn channels update`

Update selected fields; Core retains masked secret values on write-back.

```console
Usage: solwyn channels update [OPTIONS] CHANNEL_ID
```

| Argument or option | Meaning | Default |
| --- | --- | --- |
| `channel_id` | ` (STRING; required)` | `None` |
| `--name` | ` (STRING)` | `None` |
| `--secret-stdin` | ` (BOOL)` | `False` |
| `--config-stdin` | ` (BOOL)` | `False` |
| `--secret-field` | ` (STRING)` | `None` |
| `--channel` | ` (STRING)` | `None` |
| `--chat-id` | ` (STRING)` | `None` |

```text
Endpoint: GET then PUT /api/v1/account/notification-channels/{channel_id}
Auth: login; owner for mutations
Exit codes: 0 success; 1 generic/API or delivery failure; 2 usage; 3 auth; 5 not found
JSON schema: solwyn.channels.v1
Secrets only through --secret-stdin, --config-stdin JSON, or SOLWYN_CHANNEL_SECRET; never command arguments.
Omitted values stay unchanged. Masked secrets retain stored credentials. JSON null clears individual config fields only if the channel remains usable. Type is immutable.
```
