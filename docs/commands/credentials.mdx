---
title: CLI logins
---

List and revoke the CLI logins on your user. Each `solwyn login` creates one,
named by its `--label` (the short hostname by default). Tokens are never shown;
the list shows each login's ID, label, scopes, creation, last use and expiry,
and marks the login this CLI is using. Revocation is immediate: the next request
with that login fails.

```sh
solwyn credentials list
solwyn credentials revoke 91be7d03
solwyn credentials revoke --current
```

`revoke` takes a login ID or a unique prefix of at least 8 characters. A prefix
that matches no active login exits 5; one that matches several exits 2.
`--current` revokes the login in use and clears it from the keychain. Revoking
only removes access, so any of your logins may revoke any other, itself
included, without a browser approval. Both commands need a Solwyn login; a
project key cannot list logins. The dashboard shows the same list under
Settings, CLI logins.

Global `--project`, `--api-url` and output flags precede the command.
Use `--json` for the schema named below unless the command emits plain text.

## `solwyn credentials`

List and revoke CLI logins.

```console
Usage: solwyn credentials [OPTIONS] COMMAND [ARGS]...
```

```text
Endpoint: composite router for CLI login subcommands
Auth: login
Exit codes: 0 success; 2 usage
JSON schema: varies by subcommand
```

## `solwyn credentials list`

List your active CLI logins.

```console
Usage: solwyn credentials list [OPTIONS]
```

```text
Endpoint: GET /api/v1/cli/credentials
Auth: login
Exit codes: 0 success; 1 generic/API; 2 usage; 3 auth
JSON schema: solwyn.credentials.list.v1
Lists active logins only. Tokens are never shown.
```

## `solwyn credentials revoke`

Revoke one of your CLI logins. Revocation is immediate.

```console
Usage: solwyn credentials revoke [OPTIONS] [CREDENTIAL_ID]
```

| Argument or option | Meaning | Default |
| --- | --- | --- |
| `credential_id` | `CLI login ID, or a unique prefix of 8 or more characters. (STRING)` | `None` |
| `--current` | `Revoke the login in use. (BOOL)` | `False` |

```text
Endpoint: GET /api/v1/cli/credentials; DELETE /api/v1/cli/credentials/{id}
Auth: login
Exit codes: 0 success; 1 generic/API; 2 usage; 3 auth; 5 not found
JSON schema: solwyn.credentials.revoke.v1
Accepts an ID or a unique prefix of at least 8 characters.
--current revokes the login in use and clears it from the keychain.
```
